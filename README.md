# 呪契の騎士(じゅけいのきし)

実機に近い打ち心地と演出を目指す、ブラウザで遊ぶオリジナルのパチンコゲームです。
仮想の玉だけで遊び、課金、換金、景品はありません。

> **現在の状態:** 段階0(開発環境の準備)が完了しました。まだゲームのコードはありません。
> 下の「開発の始め方」の手順で、段階1から作っていきます。

## ゲームの概要

- 1,000玉を持って挑戦を始めます。
- 全10ステージの目標玉数を、通常時の回転数の期限内に超えると先へ進みます。
- 期限切れで未達か、持ち玉がなくなると挑戦終了です。記録だけ残して一からやり直します。
- 期限のない記録挑戦モードも用意します。
- 大当り確率は 1/150(最初の設定)、1/319.6、1/349.9 から選べます。

## 方針

| 項目 | 内容 |
|---|---|
| 端末 | PC優先、スマホでも動く |

## 開発の始め方

1. このフォルダでClaude Codeを起動します。
2. [docs/claude-code-prompts.md](docs/claude-code-prompts.md) の「段階0」を渡します。
3. 段階0が終わると、次のコマンドが使えるようになります。

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発用サーバーで遊ぶ |
| `npm test` | 自動テストを実行する |
| `npm run build` | 公開用のファイルを作る |
