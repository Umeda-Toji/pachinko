# Claude Code用プロンプト

上から順に、1つずつClaude Codeへ貼り付けて使います。
終わるたびに遊んで確かめ、問題がなければ次へ進みます。

## 段階0: 開発環境の準備

```text
CLAUDE.md、docs/requirements.md、docs/game-spec.md を読んでください。

今回は開発環境の準備だけを行います。ゲーム機能はまだ作りません。

作業内容:
1. Node.jsとnpmが使えるか確認する
2. Vite、TypeScript、Three.js、Vitestのプロジェクトを作る
3. npm run dev、npm test、npm run build を使えるようにする
4. CLAUDE.mdのフォルダ構成に合わせて src/ と tests/ を作る
5. 画面に「呪契の騎士」と表示する最小のページを作る
6. .gitignoreを作り、Gitで管理できるようにする

実装前に計画と不明点を教えてください。
終わったら、実行したコマンドの結果と、私が確認する手順を報告してください。
```

## 段階1: 球と打ち心地

### 1-A: 物理の計算

```text
CLAUDE.md と docs/game-spec.md の「球と盤面」を読んでください。

今回は画面なしで動く、球と釘の物理計算を作ります。

作業内容:
1. src/physics/ に、球、釘、壁、ヘソの2D物理を作る
2. 計算間隔を1/240秒に固定する
3. ハンドルの強さを0〜1で受け取り、0.6秒に1発の発射を計算する
4. 球が釘を貫通しないようにする
5. 釘の配置をデータとして持ち、数値で調整できるようにする
6. 球を自動で打ち、ハンドルの強さごとのヘソ入賞率を出すテストを作る

目標:
ハンドルが最適なとき、発射14.9玉に1回、±10%でヘソへ入る。

まだ抽選、大当り、3Dの見た目は作りません。
実装前に計画と不明点を教えてください。
終わったら、ハンドルの強さごとの入賞率を表で報告してください。
```

### 1-B: 打てる画面

```text
CLAUDE.md を読み、1-Aの物理を画面で打てるようにしてください。

作業内容:
1. Three.jsで正面固定の視点を作り、盤面、釘、球を仮の見た目で表示する
2. PCはハンドルのドラッグとホイール、スペースキーのストッパーで操作する
3. スマホは画面上のハンドルを指で回して操作する
4. 持ち玉、発射数、ヘソ入賞数、1回転あたりの消費を画面に表示する
5. 重力、反発、発射の強さを変えられる調整パネルを開発時だけ表示する

見た目はまだ作り込みません。打ったときの球の動きを優先します。
実装前に計画と不明点を教えてください。
終わったら、私が試す手順を3つ以内で教えてください。
```

```text
4. 音量調整とミュートを付ける
5. スマホでも、最初の操作の後に音が鳴るようにする

実装前に計画と不明点を教えてください。
```

```text

5. 電チューとアタッカーを物理と連動させる
6. 払い出し音、図柄の音、仮のBGMを作る
7. 受け入れ基準の抽選テストを100万回で実行する

先バレ、予告、ノルマはまだ作りません。
実装前に計画と不明点を教えてください。
```
