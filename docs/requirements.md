# 要件定義

更新日: 2026-11-05

## 目的

実機に近い打ち心地と演出を、お金をかけずに友達と遊べるWebアプリにします。
手本は鬼がかりver.とseason2のゲーム性で、キャラ、楽曲、映像はすべてオリジナルです。

## 範囲

**作るもの**

- 球の物理演算、釘、ハンドル操作を備えた正面固定の3Dパチンコ台
- 先バレ、保留、予告、リーチ、大当り、RUSHの演出と音
- 持ち玉を増やして挑戦を続け、失敗すれば一からやり直すゲーム進行

**作らないもの**

- 課金、換金、景品
- リゼロのキャラ、楽曲、映像、ロゴ、作品名を使った表現
- 初期版の協力プレイとランキング共有

## 決定事項

| 項目 | 内容 |
|---|---|
| 端末 | PC優先、スマホでも動く |
| 描画 | 正面固定の3D |
| 世界観 | オリジナルのダークファンタジー。呪いの契約が主軸で、背景が変わる演出も入れる |
| 素材 | 必ず無料、コードで生成、統一感を持たせる |
| 液晶 | 影絵のキャラと魔法陣 |
| 声 | 合成の呪文声、セリフは文字で表示 |
| 確率 | 最初は軽めの1/150。1/319.6と1/349.9も設定で選べる |
| 初期の持ち玉 | 1,000玉 |
| 進行 | ノルマ制が基本で、期限は通常時の回転数で測る。期限なしの記録挑戦も実装 |
| やり直し | 持ち玉と進行をリセットし、記録だけ残す |
| 友達要素 | まず一人用で完成、公開は友達まで |
| 最初の試作 | 球と打ち心地 |
| ハンドル | PCはドラッグとホイール、スマホは指で回す(仮) |
| 技術 | TypeScriptとThree.js。盤面の物理は自作の2D計算、音はWeb Audioを仮案とする |

## 機能要件

| 領域 | 要件 | 段階 |
|---|---|---|
| 球 | 直径11mm、5gを基準に計算し、釘や役物に当たって落ちる | 1 |
| 発射 | 0.6秒に1発。ハンドルの角度で飛距離が連続して変わり、ストッパーで止められる | 1 |
| 釘 | 250玉18回転を目標に調整する | 1 |
| 盤面 | 通常時は左打ちでヘソへ。大当りとRUSH中は右打ちで電チューとアタッカーへ | 1 |
| 筐体 | ガラス、金属、LED、役物の質感を3Dで表現する | 2 |
| 抽選 | 入賞時に当落を決める。確率は設定ごとの表で管理する | 3 |
| 液晶 | 図柄変動、影絵キャラ、魔法陣、炎、光をコードで描き、演出で背景を変える | 3 |
| 大当りとRUSH | ラウンド消化、出玉表示、ST、電サポ、右打ち指示を実装する | 3 |
| 先バレ | モード設定時だけ、入賞の瞬間に専用音と赤・白の発光を出す | 4 |
| 予告とリーチ | 保留変化、連続予告、SPリーチ、ボタン演出を入れ、当落に連動させる | 4 |
| カスタム | ノーマル、先バレ、先読みチャンス、メリハリ、プレミア | 4 |
| 振動 | 対応端末では振動させ、非対応なら画面の揺れで代用する | 4 |
| 音 | 発射、釘、入賞、先バレ、BGM、呪文声をコードで生成する | 1〜4 |
| 進行 | ノルマモード、記録挑戦モード、終了画面、記録保存を実装する | 5 |
| 注意表示 | 大当り後と待機中にのめり込み注意の文言を2秒以上出す | 5 |
| 検証 | 大当り確率、継続率、各演出の信頼度を自動テストで測る | 3〜5 |

## 非機能要件

| 項目 | 要件 |
|---|---|
| 動作速度 | PCは60fps、スマホは30fpsを目標にし、画質を自動で下げられるようにする(目標は仮) |
| 対応環境 | Windows PCとiPhoneの主要ブラウザで実機確認する |
| 保存 | 進行と記録はブラウザ内に保存する。後から共有機能を足せるように分けて設計する |
| 費用 | 有料ツールと有料素材を使わない。公開先の無料条件は公開前に確認する |
| テスト | 抽選は乱数の種を固定でき、結果を再現できる |

## 権利と公開

- アプリ内でリゼロの作品名、キャラ名、機種固有の演出名を使いません。
- 先バレ音は実機の「ポキューン」を録音も模倣もせず、新しく作ります。
- 仮想の玉を現金や景品と結びつけません。
- 公開は友達に伝えたURLだけにし、検索に載らない設定にします。
- 一般公開へ広げる場合は、法律面も含めて改めて確認します。
